# Project Management CLI Tool

## Overview

The Project Management CLI Tool is a Python command-line application that allows administrators to manage users, projects, and tasks. The application demonstrates object-oriented programming, file handling, modular programming, and the use of external Python packages.

## Features

* Create and manage users
* Create projects and assign them to users
* Add tasks to projects
* Mark tasks as completed
* View projects for a specific user
* Save data using JSON file storage
* Display information in formatted tables using the tabulate package
* Menu-driven command-line interface

## Installation

1. Clone the repository:

git clone https://github.com/antoniocallie97-web/Project_Management_cli.git

2. Navigate to the project directory:

cd Project_Management_cli

3. Create and activate a virtual environment:

python3 -m venv venv

source venv/bin/activate

4. Install dependencies:

pip install -r requirements.txt

## Running the Application

Run the following command:

python main.py

or

python3 main.py
